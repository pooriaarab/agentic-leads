# Agentic leads

Use search_leads with query, area, source or sources, limit, and file.
Dry runs default to true. Preview before an authorized live call.
Use list_sources to check key status and get_cost_report for session totals.
The CLI exposes search, sources, costs, doctor, mcp, help, and version.
The SDK exports findLeads and six adapters from agentic-leads.
Respect guard denials and report failed adapters as errors.
